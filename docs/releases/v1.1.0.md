# Emby.Zattoo v1.1.0 — Chaînes lisibles et capacités du compte

Cette version adapte automatiquement le catalogue, le guide et la capacité du
tuner aux droits techniques réellement observés pour le compte Zattoo. Son but
est d'éviter de charger dans Emby des chaînes qui ne pourront pas être lues et
de réduire le travail inutile effectué pendant l'actualisation du guide.

## Points forts

- nouveau mode **Playable channels only**, recommandé et sélectionné par défaut ;
- import limité aux chaînes possédant au moins une qualité disponible non-DRM ;
- conservation des chaînes mixtes avec repli automatique vers leur meilleure
  qualité lisible non-DRM ;
- modes facultatifs pour conserver les chaînes temporairement indisponibles ou
  afficher le catalogue complet à des fins de diagnostic ;
- parsing, cache mémoire et enrichissement des descriptions EPG limités aux
  chaînes effectivement importées ;
- prise en compte de l'option Emby **Import favorites only** dans cette même
  sélection EPG ;
- détection des capacités techniques sans dépendre du nom commercial de
  l'abonnement : replay, limite d'enregistrements cloud, résolution non-DRM et
  nombre de flux simultanés ;
- ajustement du nombre de tuners Emby et verrou interne empêchant le plugin de
  dépasser la capacité détectée ;
- possibilité de regarder une chaîne pendant qu'Emby en enregistre une autre
  lorsque le compte autorise plusieurs flux, sans ajouter de gestion
  multi-utilisateur au plugin ;
- compteurs anonymes dans les logs et dans la commande `survey`.

## Résultat observé

Sur le catalogue utilisé pour la validation, le mode recommandé importe 264
chaînes lisibles sur 493. Il écarte 18 chaînes disponibles uniquement avec DRM
et 211 chaînes sans stream disponible. Le guide natif Emby continue de fournir
sept jours de programmes mais ne matérialise plus les chaînes exclues.

Les résultats varient selon le compte, la région, les bouquets et les données
publiées par Zattoo.

## Installation

1. Télécharger `Emby.Zattoo-v1.1.0.zip` ou `Emby.Zattoo.dll`.
2. Arrêter Emby Server.
3. Remplacer l'ancienne `Emby.Zattoo.dll` dans le dossier `plugins`.
4. Vérifier qu'aucune ancienne `Emby.Zattoo.Core.dll` n'est présente.
5. Redémarrer Emby Server.
6. Ouvrir les paramètres de **Zattoo Live TV** et vérifier **Channel import
   mode**.
7. Lancer la tâche native **Actualiser le guide**.

La source TV et les paramètres existants peuvent être conservés. Après la
première actualisation, Emby retire de son catalogue les chaînes exclues par le
mode choisi.

Une souscription Emby Premiere active reste nécessaire pour les fonctions Live
TV et DVR d'Emby.

## Cache EPG lors de la mise à niveau

Le fichier `guide-details-cache-v1.jsonl` existant est conservé afin d'éviter un
rechargement complet. Les anciennes entrées appartenant aux chaînes désormais
exclues ne sont plus renouvelées. Elles disparaissent progressivement après
expiration et compaction ; la taille du fichier ne diminue donc pas forcément
immédiatement après l'installation.

## Capacité de lecture et d'enregistrement

Le plugin utilise une limite de flux fournie par la session lorsqu'elle est
disponible. Dans le cas contraire, il emploie une estimation prudente issue des
limites numériques du compte et l'indique explicitement dans les logs.

Cette capacité sert au scénario lecture et enregistrement simultanés. Elle ne
réserve pas les flux utilisés dans une autre application Zattoo et ne crée pas
de politique multi-utilisateur dans Emby.

## Limites connues

- seuls les flux non-DRM sont pris en charge ;
- aucune tentative de contournement Widevine ou DRM n'est effectuée ;
- Replay et les enregistrements hébergés par Zattoo ne sont pas intégrés ;
- une limite de flux inférée devra être confirmée par un test réel de lecture
  pendant un enregistrement ;
- les endpoints Zattoo utilisés ne constituent pas une API publique garantie.

Ce projet est non officiel et n'est affilié ni à Zattoo ni à Emby. Son
utilisation doit respecter l'abonnement, les conditions des fournisseurs et le
droit applicable.
