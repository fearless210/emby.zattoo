# Emby.Zattoo v1.2.0 — Réouverture du flux et favoris du compte

Un flux Live qui s'arrêtait de lui-même tronquait l'enregistrement en cours sans
aucun message. Il est désormais rouvert sans interrompre ce qu'Emby écrit. Une
case **Import favorites only** est ajoutée aux réglages du plugin.

## Ce qui est corrigé

### Un flux interrompu tronquait l'enregistrement sans message

Le plugin ne réagissait que si FFmpeg sortait avec un code non nul. Une sortie
propre en plein direct repartait en silence : Emby y voyait une fin normale et
refermait l'enregistrement, sans erreur ni ligne de journal.

Toute fin de flux non demandée est maintenant traitée comme une panne :

- elle est qualifiée et journalisée avec sa cause et le code de sortie ;
- si une nouvelle URL a une chance, **le flux est rouvert** — nouvelle URL,
  nouveau FFmpeg, la copie reprend vers le même consommateur. Emby ne voit pas
  de fin de fichier et l'enregistrement continue. Mesuré à 138 ms sur une panne
  provoquée ;
- une cause que rouvrir ne répare pas, comme une commande FFmpeg que le système
  ne sait pas exécuter, arrête le flux immédiatement ;
- les réouvertures sont plafonnées à trois par fenêtre glissante de cinq
  minutes.

Aucun renouvellement préventif n'est en place : une mesure de trois heures de
consommation continue n'a montré ni expiration de l'URL signée, ni arrêt de la
fenêtre de segments.

### L'option d'import des favoris était inactivable

La v1.1.0 annonçait la prise en compte de l'option Emby **Import favorites
only**. Le code l'honorait, mais Emby n'affiche pas cette case pour un tuner de
plugin : rien ne permettait de l'activer. Le README conseillait d'utiliser une
case inexistante.

## Ce qui est ajouté

### Import limité aux favoris du compte

Une case **Import favorites only** dans les réglages du plugin. Cochée, seules
les chaînes marquées comme favorites dans le compte Zattoo sont importées.

Elle se cumule avec `Channel groups` :

| Channel groups | Import favorites only | Chaînes importées |
| --- | --- | --- |
| vide | décoché | tout le catalogue lisible |
| vide | coché | tous vos favoris |
| `Sport` | décoché | tout le bouquet Sport |
| `Sport` | coché | vos favoris qui sont aussi dans le bouquet Sport |

Pour importer tous vos favoris sans exception, laissez `Channel groups` vide.

Si le compte n'a aucun favori parmi les chaînes importables, l'actualisation est
refusée et la grille précédente conservée plutôt qu'effacée.

Un réglage modifié ne s'applique qu'à la prochaine actualisation des chaînes ;
entre-temps Emby sert sa liste en cache, qui survit à un redémarrage.

### Deux lignes de journal à chaque actualisation

Le nombre de favoris rapportés par le compte, et le détail du filtrage du
catalogue jusqu'à la sélection finale — utile pour identifier le filtre qui a
réduit ou vidé la liste.

### Une commande de diagnostic `stream-lifetime`

Elle suit une playlist signée et ses segments à intervalle régulier, et rapporte
combien de temps l'URL reste servie. Réservée au contributeur.

## Installation

1. Télécharger `Emby.Zattoo-v1.2.0.zip` ou `Emby.Zattoo.dll`.
2. Arrêter Emby Server.
3. Remplacer l'ancienne `Emby.Zattoo.dll` dans le dossier `plugins`.
4. Redémarrer Emby Server.

Les identifiants, les réglages, la source TV et le cache du guide sont
conservés. Aucune actualisation du guide ni des chaînes n'est nécessaire, sauf
si vous cochez **Import favorites only**.

## Portée de la validation

Réouverture du flux validée sur Emby 4.9.5.0 sous Linux avec un compte réel :
lecture et enregistrement normaux sans réouverture parasite, panne provoquée
rouverte en 138 ms, enregistrement mené à terme et fichier lisible.

211 tests automatisés s'exécutent sous .NET 8 avec des données entièrement
fictives ; aucun ne contacte le fournisseur. La réouverture et la classification
en situation ne sont pas couvertes — elles exigent un vrai FFmpeg et un vrai
flux — et la logique décidable en a été extraite dans des classes qui, elles,
le sont.
