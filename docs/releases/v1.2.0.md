## Ce qui est ajouté

### Import limité aux favoris du compte

Une case **Import favorites only** apparaît dans les réglages du plugin. Cochée,
seules les chaînes marquées comme favorites dans le compte Zattoo sont
importées.

Le plugin savait déjà le faire, mais par une case d'Emby — et Emby ne l'affiche
pas pour un tuner de plugin. La v1.1.0 annonçait la prise en compte de cette
option ; le code l'honorait bien, mais rien ne permettait de l'activer. Le
réglage vit désormais là où l'utilisateur le cherche.

**Les filtres se cumulent.** `Channel groups` et les favoris sont deux
conditions, et une chaîne renseignée dans les deux doit satisfaire les deux :

| Channel groups | Import favorites only | Chaînes importées |
| --- | --- | --- |
| vide | décoché | tout le catalogue lisible |
| vide | coché | tous vos favoris |
| `Sport` | décoché | tout le bouquet Sport |
| `Sport` | coché | vos favoris qui sont aussi dans le bouquet Sport |

C'est ce cumul qui permet « mes chaînes de sport favorites ». Si vous voulez
tous vos favoris sans exception, laissez `Channel groups` vide.

**Une actualisation qui ne ramènerait aucune chaîne est refusée.** Si le compte
n'a aucun favori parmi les chaînes importables, la grille précédente est
conservée plutôt qu'effacée, et le journal dit pourquoi. La garde ne couvre
volontairement que l'étage des favoris : un filtre de bouquets qui vide la
sélection garde son comportement actuel.

Deux lignes s'ajoutent au journal à chaque actualisation, que l'option soit
active ou non : le nombre de favoris rapportés par le compte, et le détail du
filtrage du catalogue jusqu'à la sélection finale.
