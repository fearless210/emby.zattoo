# Emby.Zattoo v1.0.0 — Première version fonctionnelle

Cette version marque le premier parcours complet validé sur un serveur Emby
Linux : configuration du compte, import des chaînes, lecture Live, guide TV,
descriptions enrichies et enregistrements DVR.

## Points forts

- installation avec une seule DLL et configuration native dans Emby ;
- authentification Zattoo et renouvellement borné de la session ;
- import des chaînes, numéros, favoris et logos ;
- lecture des flux HLS7 non-DRM avec sélection vidéo/audio et remux MPEG-TS sans
  réencodage ;
- fermeture propre des flux et des processus FFmpeg ;
- guide Zattoo intégré à la tâche native **Actualiser le guide** d'Emby sur une
  profondeur configurable allant jusqu'à 14 jours ;
- prise en charge de la planification et de l'exécution des enregistrements DVR ;
- enrichissement asynchrone des descriptions par lots bornés ;
- cache persistant qui évite de recharger les programmes inchangés après une
  actualisation ou un redémarrage ;
- fenêtre glissante de 24 heures, complétée par les chaînes favorites, afin de
  limiter le nombre d'appels et la taille du cache ;
- absence de credentials, cookies, tokens ou URL signées dans les logs du
  plugin.

## Installation

1. Télécharger `Emby.Zattoo-v1.0.0.zip` ou `Emby.Zattoo.dll`.
2. Arrêter Emby Server.
3. Supprimer toute ancienne copie de `Emby.Zattoo.Core.dll`.
4. Copier uniquement `Emby.Zattoo.dll` dans le dossier `plugins` d'Emby.
5. Redémarrer Emby et configurer **Zattoo Live TV** depuis le tableau de bord.
6. Ajouter la source TV **Zattoo**, puis lancer **Actualiser le guide**.

Une souscription Emby Premiere active est nécessaire pour les fonctions Live TV
et DVR d'Emby.

## Mise à niveau depuis v0.2.4

La source TV existante et les paramètres du compte peuvent être conservés. Le
premier enrichissement crée `guide-details-cache-v1.jsonl` dans le dossier de
données du plugin. Une actualisation native supplémentaire applique dans Emby
les descriptions chargées en arrière-plan.

## Limites connues

- seuls les flux non-DRM sont pris en charge ;
- Replay et les enregistrements hébergés par Zattoo ne sont pas intégrés ;
- les endpoints Zattoo utilisés ne constituent pas une API publique garantie ;
- la lecture a été validée avec Emby Web sous Emby 4.9 ;
