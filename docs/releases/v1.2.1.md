# Emby.Zattoo v1.2.1 — Compatibilité avec Emby 4.10

Après la mise à jour vers Emby 4.10, aucune chaîne ne s'ouvrait plus. Cette
version répare le plugin pour Emby 4.10 sans rien changer à son fonctionnement,
et le même fichier continue de fonctionner sur Emby 4.9.

## Ce qui est corrigé

### Aucune chaîne ne s'ouvrait sur Emby 4.10

Emby affichait « Aucun flux compatible n'est actuellement disponible » sur
toutes les chaînes, et son journal indiquait :

```text
Method 'AddConsumer' in type 'Emby.Zattoo.Plugin.LiveTv.ZattooLiveStream'
from assembly 'Emby.Zattoo' does not have an implementation.
```

Emby 4.10 a changé la façon dont il compte les spectateurs d'un flux Live : il
ne les compte plus lui-même et demande désormais au plugin de le faire. Le
plugin ne connaissait pas cette nouvelle demande, et Emby refusait donc de
charger la partie du plugin qui ouvre les flux.

Le plugin tient maintenant ce compte lui-même sur Emby 4.10 et laisse Emby 4.9
le tenir comme avant. Lecture, enregistrement, réouverture d'un flux
interrompu, limite de flux simultanés du compte : rien ne change.

## Installation

1. Télécharger `Emby.Zattoo-v1.2.1.zip` ou `Emby.Zattoo.dll`.
2. Arrêter Emby Server.
3. Remplacer l'ancienne `Emby.Zattoo.dll` dans le dossier `plugins`.
4. Redémarrer Emby Server.

Les identifiants, les réglages, la source TV et le cache du guide sont
conservés. Aucune actualisation du guide ni des chaînes n'est nécessaire.

Le même fichier convient à Emby 4.9 et à Emby 4.10 : il n'y a pas de version
distincte à choisir.

## Portée de la validation

Lecture validée sur Emby 4.10.1.0 sous Linux avec un compte réel.

Sur Emby 4.9, le plugin a été vérifié en chargeant le fichier livré contre le
SDK 4.9 : il se charge sur les deux versions, alors que la v1.2.0 échouait
exactement comme décrit plus haut face au SDK 4.10.

218 tests automatisés s'exécutent sous .NET 8 avec des données entièrement
fictives ; aucun ne contacte le fournisseur. Les nouveaux tests couvrent le
compte des spectateurs et vérifient que le plugin reste chargeable par l'une
comme par l'autre version d'Emby.
